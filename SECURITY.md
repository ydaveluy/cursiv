# Security policy

## Report a vulnerability

Report security vulnerabilities through
[GitHub's private reporting form](https://github.com/ydaveluy/cursiv/security/advisories/new).

Include:

- The affected Cursiv version or commit.
- A minimal example and steps to reproduce the problem.
- The potential impact and relevant build or runtime settings.

Keep vulnerability details private while we investigate and coordinate a fix.

For bugs without a security impact, open a
[regular issue](https://github.com/ydaveluy/cursiv/issues).
